# 工程实现说明

该仓库已从初始骨架完成到 V2 M1–M4：React 编辑器、Go 正式渲染、resvg PNG Worker、PostgreSQL 状态、Redis 队列/限流、私有对象存储、身份与设备会话、订单/支付/退款/发票、管理后台、资源授权、审计和上线安全基线均已接通。

## 运行模式

- 本地模式：原子 JSON 状态、本地有界队列、私有文件目录，方便零依赖开发和测试。
- 生产模式：`APP_DATABASE_URL` 启用 PostgreSQL JSONB 事务状态；`APP_REDIS_URL` 启用 Redis 阻塞队列与 Lua 原子限流；Worker 独立渲染 PNG。
- PostgreSQL 规范化表保留供报表与后续在线拆分，当前 API 业务事务以 `platform_state` 单行 JSONB 为事实源，避免跨表部分提交。

## 一致性与恢复

SealConfig、xorshift32、逻辑坐标与 rendererVersion 由前后端共享规则约束。generationKey 包含规范化配置、用户、格式和水印策略。API 重启会把 `queued/rendering` 任务恢复为 queued 并重新入队，Worker 写对象与任务状态保持幂等。
